# 🪄 אלגברה-קדברה

אפליקציית לימוד משחקית לכיתה ט' (מסלול 5 יח"ל) — מפת הרפתקה עם עולמות, שלבים ובוסים, ופרסים אמיתיים שההורים מגדירים.

## הרצה

```bash
npm install
npm run dev      # שרת פיתוח
npm test         # בדיקות יחידה (מחוללי שאלות, בדיקת תשובות, לוגיקת התקדמות)
npm run build    # בנייה סטטית ל-dist/ (מתאים ל-Netlify / Vercel / GitHub Pages)
```

## מה בנוי (שלב 1 — MVP)

- **שלד RTL מלא** בעברית; נוסחאות ב-KaTeX מוצגות LTR בתוך הטקסט.
- **מסך פתיחה** עם ברכה אישית ולהבת רצף, **מסך בית** (המשך מסע, הפרס הבא, יעד יומי, משימות תיקון), **מפת עולמות** וניווט תחתון.
- **עולם מלא: 🌊 מפרץ המשוואות** — 7 שלבים + בוס (קרקן המשוואות):
  - ⚡ ריצת מהירות: 10 שאלות, זמן בונוס, קומבו.
  - 🪜 צעד-אחר-צעד: בוחרים את הצעד הנכון הבא, עם רמז והסבר לכל צעד.
  - 👑 בוס: פס חיים, כל תשובה נכונה פוגעת בו; "מתקפה מיוחדת" של תרגיל רב-שלבי.
- **מחוללי שאלות** (5 רמות קושי): משוואות ממעלה ראשונה, משוואות עם שברים (כולל נעלם במכנה ותחום הצבה), אי-שוויונות (כולל היפוך סימן), מערכות שתי משוואות. לכל שאלה 3 רמזים מדורגים ופתרון מלא.
- **קושי מסתגל** (3 נכונות ברצף ← עולה, 2 טעויות ← יורד) ו**משימות תיקון** (שאלות שנכשלו חוזרות אחרי 30 דקות).
- **XP, רמות עם תארים, כוכבים, מטבעות, רצף ימים, הישגים, קלפי מתמטיקאים** (קלף לכל בוס).
- **לוח פרסים** + **תיבת אוצר** כשפרס נפתח. סוגי יעדים: XP מצטבר, ניצחון בבוס, רצף ימים, שלבים עם 3 כוכבים, דיוק בנושא.
- **אזור הורים** (קוד PIN): ניהול פרסים וסימון "מומש" (אי אפשר לשנות יעד אחרי שנקבע), מעקב זמן ודיוק לפי נושא, סדר עולמות ופתיחה ידנית, יעד יומי, גיבוי/שחזור לקובץ.
- **צלילים** מסונתזים ב-Web Audio (אין קבצים לטעון), מוזיקת רקע עדינה לכל עולם, עוצמה נפרדת למוזיקה ולאפקטים. מושתק עד הלחיצה הראשונה.
- **הגדרות**: שם, אווטאר, מצב כהה, גודל טקסט.
- שמירה מקומית (localStorage), בלי שרת.

## 🧙 הקוסם המדריך (אבן דרך 2 — A1–A2)

כשמיה נתקעת, הקוסם מוביל אותה לפתרון **בלי לחשוף את התשובה**:

- **סולם עזרה** לכל צעד: שאלה מכוונת ← תזכורת כלל ← דוגמה מקבילה (מספרים אחרים) ← השלמת חסר. אחרי שתי השלמות שגויות הצעד מתפרק לתת-צעדים.
- **אבחון טעויות:** כל מחולל מחזיר `distractors` עם קוד טעות (למשל `sign-move`). תשובה שגויה שתואמת קוד קופצת ישר לצעד הרלוונטי עם תזכורת ממוקדת.
- **פרופיל למידה** (`progress.learner`): mastery לכל מיומנות (+0.08/+0.04/+0.01/−0.05, דעיכה של 0.02 לשבוע), טעויות נפוצות, ואיזה סוג עזרה עובד לה. נשמר מקומית ונכלל בגיבוי.
- **התאמה אישית:** דרגת הפתיחה לפי mastery (≥0.7 שאלה מכוונת, <0.4 דוגמה), ובחירת דרך הפתרון (למשל הצבה מול השוואת מקדמים) לפי המיומנויות החזקות שלה.
- אחרי טעות: "בואי ננסה ביחד" במקום הצגת התשובה. "הראי לי איך" רק אחרי שהסולם מוצה.
- בדיקות יחידה מוודאות שאף רמז, באף דרגה, לא מכיל את התשובה הסופית (שקילות עם math.js), ושאף distractor לא שווה לתשובה.

הקוד ב-`src/tutor/`: `engine.ts` (diagnose, choosePath, startSession, moreHelp, answerBlank, getNextHelp), `profile.ts` (recordOutcome), `leak.ts` (findLeak), `equationSteps.ts` (תוכן הרמזים).

## מבנה הקוד

```
src/
  engine/        מספרים רציונליים, עיצוב LaTeX, בדיקת תשובות (math.js), קושי מסתגל
  tutor/         הקוסם המדריך: מנוע העזרה, פרופיל הלמידה, תוכן הרמזים ובדיקת דליפת תשובה
  generators/    מחולל לכל סוג שאלה + בדיקות שמוודאות שהתשובה פותרת את המשוואה ושהמספרים "נחמדים"
  content/       הגדרת עולמות ושלבים, קלפי מתמטיקאים
  store/         מצב המשחק (Zustand + persist) ולוגיקה טהורה: רמות, רצף, פתיחת עולמות, פרסים, הישגים
  audio/         מנוע צלילים
  components/    רכיבי ממשק משותפים (נוסחאות, מקלדת מתמטית, תיבת אוצר...)
  screens/       מסכים; screens/play — ריצת מהירות, צעד-אחר-צעד, בוס, תיקון
```

הוספת עולם חדש: כותבים מחוללים ב-`src/generators/<topic>/`, רושמים אותם ב-`src/generators/index.ts`, וממלאים `levels` לעולם ב-`src/content/worlds.ts`. עולם בלי שלבים מוצג במפה כ"בקרוב" ומדולג בשרשרת הפתיחה.
